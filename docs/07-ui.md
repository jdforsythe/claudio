# 07 — User Interface

This document describes every visible surface of Claudio: the menu bar item, the popover, the floating HUD, the settings window, global hotkeys, and the view models that feed them. All UI code lives in the `ClaudioApp` executable target. It compiles with SwiftPM alone: there are no storyboards, no XIBs and no asset catalogs. Icons are SF Symbols; the app icon is a prebuilt `AppIcon.icns` in `Resources/`.

Minimum deployment target is macOS 15. The UI layer is `@MainActor`. It never touches audio or files directly; every action is a method call into a view model, which forwards to a core actor.

## 1. Application lifecycle

### 1.1 Entry point

```swift
@main
struct ClaudioApp: App {
    @State private var root = CompositionRoot.shared

    var body: some Scene {
        MenuBarExtra {
            PopoverView()
                .environment(root.sessionsViewModel)
                .environment(root.playbackViewModel)
                .environment(root.settingsViewModel)
        } label: {
            MenuBarLabel()
                .environment(root.playbackViewModel)
                .environment(root.sessionsViewModel)
        }
        .menuBarExtraStyle(.window)

        Settings {
            SettingsWindow()
                .environment(root.settingsViewModel)
                .environment(root.sessionsViewModel)
        }
    }
}
```

`Info.plist` sets `LSUIElement = true`, so the app has no Dock icon and no main menu. `CompositionRoot.init` additionally calls `NSApplication.shared.setActivationPolicy(.accessory)` as a belt-and-braces measure for the case where the binary is run directly from `.build/` without a bundle.

### 1.2 Composition root

`CompositionRoot` is a `@MainActor final class` created once. Its initializer performs, in order:

1. `SingleInstance.ensure()` (see §1.3). If another instance is running, this call never returns: it activates the other instance and calls `exit(0)`.
2. Constructs `Paths`, `AppSettings`, `ProjectPreferences`, `KeychainStore`.
3. Constructs backends: `EdgeTTSBackend`, `AppleSpeechBackend`, `OpenAITTSBackend`, wrapped by `FallbackBackend`. `VoiceCatalog` over all three.
4. Constructs `PlaybackEngine`, `SynthesisScheduler`, `SpeechPipeline`.
5. Constructs `SessionRegistry`, `LiveAgentsProbe`, `SessionDiscovery`, `Arbiter`.
6. Constructs `ControlServer` and starts listening.
7. Constructs the four view models and hands each the actors it needs.
8. Constructs `HUDController` and `HotkeyManager`.
9. Starts discovery and the probe.
10. If `AppSettings.firstLaunchCompleted == false`, schedules `FirstLaunchHint.show()` 1.5 s after launch and sets the flag.

Every dependency is injected through initializers. Nothing reaches for `CompositionRoot.shared` after construction except the `@main` struct.

### 1.3 Single instance

`SingleInstance.ensure()` attempts to connect to the control socket at `Paths.controlSocket` and send `{"v":1,"cmd":"ping"}`. If a response arrives within 200 ms, another Claudio is running: the function sends `{"v":1,"cmd":"activate"}` (the running instance opens its popover) and calls `exit(0)`. If the socket file exists but connection is refused, the file is stale from a crash; it is removed and startup continues. `NSWorkspace` bundle-identifier checks are not used because they fail for the unbundled debug binary.

### 1.4 First launch

There is no onboarding wizard. On first launch a popover-shaped hint window (`FirstLaunchHint`, an `NSPanel` anchored under the status item) shows:

> **Claudio is in your menu bar.**
> Start a Claude Code session in any terminal and it appears here. Click a session to hear it.
> For instant stop when you type a new prompt, turn on **Hooks** in Settings → Integration.
> [Open Settings] [Got it]

The hint dismisses on either button, on click outside, or after 30 s.

## 2. Menu bar item

### 2.1 Symbols by state

`MenuBarLabel` renders a single `Image(systemName:)` chosen from `PlaybackViewModel.menuState`:

| `MenuState` | Symbol | Rendering | Tooltip |
|---|---|---|---|
| `.idle` | `waveform` | Monochrome, `.secondary` tint | "Claudio — idle" |
| `.speaking` | `waveform` | `.symbolEffect(.variableColor.iterative.reversing, isActive: true)`, `.primary` tint | "Claudio — speaking: <session title>" |
| `.paused` | `pause.circle` | Monochrome | "Claudio — paused" |
| `.muted` | `speaker.slash` | Monochrome, `.secondary` | "Claudio — muted" |
| `.catchingUp` | `waveform` | Variable colour effect plus a small `clock.arrow.circlepath` badge overlay (bottom-right, 8 pt) | "Claudio — catching up on <session title>" |

Unread count (sum of `unreadTurns.count` across non-active sessions) renders as a text overlay: a 10 pt bold rounded numeral inside a 14 pt capsule, `Color.accentColor` fill, white text, offset to the top-right of the symbol. Counts above 9 show "9+". The overlay is omitted when the count is 0.

`symbolEffect` is disabled when `NSWorkspace.shared.accessibilityDisplayShouldReduceMotion` is true; the speaking state then uses `.primary` tint only.

### 2.2 Click behaviour

Left click opens the popover (handled by `MenuBarExtra`). Right click shows a context menu, implemented by attaching an `NSMenu` to the status item via `NSStatusItem.menu` toggled in `mouseDown` of a transparent overlay view, with items:

- "Pause" / "Resume" (title reflects state)
- "Mute" / "Unmute"
- separator
- "Open Settings…" (⌘,)
- "Quit Claudio" (⌘Q)

## 3. Popover

### 3.1 Layout

`PopoverView` is 360 pt wide, height sized to content with a maximum of 560 pt, after which the session list scrolls.

│ ● Claudio redesign                                │
│   ~/dev/claudio · idle 4 m ago             [Q|A|N]│
│ ○ facility-meta-api                               │
│   ~/dev/facility-meta-api · ended          [Q|A|N]│
├──────────────────────────────────────────────────┤
│ Hooks: 7 installed              [⚙]   v1.0.0 (42) │  footer, 36 pt

### 3.2 Header

Four `Button`s with `.buttonStyle(.borderless)`, 28×28 pt, SF Symbols:

| Control | Symbol (off / on) | Action | Accessibility label |
|---|---|---|---|
| Mute | `speaker.wave.2` / `speaker.slash` | `playback.toggleMute()` | "Mute" / "Unmute" |
| Pause | `pause.fill` / `play.fill` | `playback.togglePause()` | "Pause" / "Resume" |
| Skip | `forward.end.fill` | `playback.skipSegment()` | "Skip sentence" |
| Live | `forward.end.alt.fill` | `playback.skipToLive()` | "Skip to live" |

Skip and Live are disabled (`.disabled(true)`, 40 % opacity) when nothing is queued. Live is additionally disabled unless the arbiter mode is `.catchingUp`.

Right-aligned status text, `.font(.caption)`, `.foregroundStyle(.secondary)`: "Idle", "Speaking · <title>", "Paused · <title>", "Catching up · <title>", "Muted".

### 3.3 Session rows

`SessionRow(session: Session, isActive: Bool)`:

- **Colour dot**, 10 pt circle, `SessionColor.color(for: session.colorIndex)`. Filled when status is `busy`/`waiting`/`idle`; stroked (hollow) when `ended`.
- **Title**, `.font(.body.weight(.medium))`, single line, truncating tail. Hidden-rendering tooltip shows the full session id.
- **Subtitle**, `.font(.caption)`, `.secondary`: `<abbreviated cwd> · <status text>` where cwd is abbreviated with `~` and status text is:
  - `busy` → "working"
  - `waiting` → "needs you" in `Color.orange`
  - `idle` → "idle <relative time>" using `RelativeDateTimeFormatter(unitsStyle: .abbreviated)`
  - `ended` → "ended"
- **Status glyph** before status text: `busy` → `circle.dotted` with `.symbolEffect(.rotate)`; `waiting` → `exclamationmark.circle.fill` orange; `idle` → none; `ended` → `stop.circle` secondary.
- **Unread pill**: when `session.unreadTurns.count > 0` and the session is not active, a capsule with the count, accent fill, white 11 pt bold text. Accessibility label "<n> unread turns".
- **ACTIVE** tag: `Text("ACTIVE").font(.caption2.weight(.bold)).foregroundStyle(Color.accentColor)` on the active row.
- **Level control**: `Picker` with `.pickerStyle(.segmented)`, 132 pt wide, labels "Quiet", "Answers", "Narrate", bound to `sessions.binding(forLevelOf: session.id)`. Changing it calls `SessionRegistry.setLevel(sessionID:level:)` immediately. Accessibility label "Speech level for <title>".

Clicking anywhere on the row other than the picker calls `sessions.activate(session.id)`. The active row has a 4 % accent background with 8 pt corner radius. Rows are 56 pt tall with 12 pt horizontal padding.

### 3.4 Sorting

`SessionsViewModel.sortedSessions` orders by:

1. Active session first.
2. `waiting`
3. `busy`
4. `idle`, most recent `lastActivity` first
5. `ended`, most recent `lastActivity` first

Ties within a group break on `lastActivity` descending, then title.

### 3.5 Empty state

When there are no sessions:

> `waveform.slash` (32 pt, `.tertiary`)
> **No Claude Code sessions yet.**
> Start one in a terminal and it appears here.

Centered, 160 pt tall.

### 3.6 Footer

Left: hooks status, `.font(.caption)`:

| `HooksStatus` | Text | Button |
|---|---|---|
| `.disabled` | "Hooks: off" | "Turn on…" → opens Settings → Integration |
| `.installed(count)` | "Hooks: <count> installed" | none |
| `.needsRepair` | "Hooks: point elsewhere" in orange | "Repair" → `settings.repairHooks()` |
| `.error(message)` | "Hooks: error" in red, tooltip shows message | "Details…" → Settings → Integration |

Right: `gearshape` button (opens Settings, accessibility "Settings") and version text "v<CFBundleShortVersionString> (<CFBundleVersion>)" in `.caption2` `.tertiary`.

### 3.7 Keyboard

Inside the popover: ↑/↓ move a focus ring between rows; ↩ activates the focused row; ␣ toggles pause; `1`/`2`/`3` set the focused row's level to Quiet/Answers/Narrate; `⌘,` opens Settings; `Esc` closes the popover. Focus is implemented with `@FocusState private var focusedSessionID: SessionID?` and `.focusable()` on rows.

## 4. HUD

### 4.1 Panel

`HUDPanel: NSPanel` is created once by `HUDController` and reused.

```swift
final class HUDPanel: NSPanel {
    init() {
        super.init(
            contentRect: .zero,
            styleMask: [.borderless, .nonactivatingPanel],
            backing: .buffered,
            defer: false)
        level = .floating
        collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]
        isMovableByWindowBackground = true
        hidesOnDeactivate = false
        isOpaque = false
        backgroundColor = .clear
        hasShadow = true
        isReleasedWhenClosed = false
        animationBehavior = .utilityWindow
        contentView = NSHostingView(rootView: HUDView().environment(viewModel))
    }
    override var canBecomeKey: Bool { false }
    override var canBecomeMain: Bool { false }
}
```

Because `canBecomeKey` is false, clicking the HUD never steals focus from the terminal. Buttons inside it work because `NSHostingView` delivers mouse events without key status. The panel's empty areas are not click-through; a click there starts a drag.

### 4.2 Appearance

- Collapsed size 320 × 56 pt. Expanded (captions open) 320 × up to 140 pt; height follows content.
- Background `.ultraThinMaterial` with `RoundedRectangle(cornerRadius: 12, style: .continuous)` clip and a 0.5 pt `.separator` stroke.
- A 4 pt vertical colour bar on the leading edge, full height, `SessionColor.color(for:)` of the active session; `.gray` when no session is active.
- Height changes animate with `.animation(.easeInOut(duration: 0.18))`; the panel frame is updated in `HUDController.panelDidResize` keeping the top-left corner fixed.

### 4.3 Content

```
┌─┬──────────────────────────────────────────────┐
│▌│ ● Yard                   ◐  ▮▮▮▮▯▯ 4/6   ⏸ ⏭ ⏩ ⌄ │
│▌│ Catching up 2/3 · Skip to live                 │  (only while catching up)
│▌│ Vea needs permission — Switch (↩)              │  (prompt stack, 0–3 rows)
├─┴──────────────────────────────────────────────┤
│  The parser attaches at end of file and never   │  (captions, when expanded)
│  replays history, so a resumed session speaks   │
│  only ▐new▌ records.                            │
└────────────────────────────────────────────────┘
```

Row 1 (always visible, 56 pt):
- Session colour dot (8 pt) and title, `.font(.system(size: 13, weight: .semibold))`, truncating.
- State glyph: speaking `waveform` with variable colour; paused `pause.fill`; catching up `clock.arrow.circlepath`; idle `waveform` tertiary.
- Segment progress: `ProgressView(value: done, total: total)` 60 pt wide, `.progressViewStyle(.linear)`, with text "<done>/<total>" in `.caption2.monospacedDigit()`. `done` and `total` come from `HUDViewModel.segmentProgress` for the current utterance.
- Transport buttons: pause/resume, skip, live (same symbols as the popover header, 22 pt hit targets).
- Captions disclosure: `chevron.down` / `chevron.up`, toggles `AppSettings.hudCaptionsExpanded`.
- Pin: `pin` / `pin.fill` at the far right, toggles `AppSettings.hudPinned`.

Row 2 (catch-up, 20 pt, only in `.catchingUp` mode): "Catching up <k>/<n>" where `k` is the turn index being spoken, plus a text button "Skip to live".

Prompt stack (`PromptStackView`): up to 3 rows of 22 pt, newest at the bottom. Each row text follows `"<title> <verb> — Switch (↩)"` where verb is "needs permission", "needs input", "is waiting", "finished". Pressing ↩ while the panel is the pointer-hovered window, or clicking the row, calls `sessions.activate(prompt.sessionID)` and removes the prompt. Each prompt auto-dismisses after 20 s. A fourth incoming prompt drops the oldest. Prompts for the active session are never shown.

### 4.4 Captions

`CaptionView` displays the current segment text as an `AttributedString`. The word range reported by `PlaybackViewModel.currentWordRange` receives `.backgroundColor = SessionColor.color(for:).opacity(0.35)` and `.foregroundColor = .primary`; the rest of the segment is `.primary` at 85 % opacity. The previously finished segment, if any, is shown above in `.secondary` at 60 % opacity, limited to 2 lines. Font is `.system(size: 13)` with `.monospacedDigit()`. Text is selectable (`.textSelection(.enabled)`) so a listener can copy what was said.

Segment changes animate with a 120 ms cross-fade. Word highlight moves without animation (a highlight that lags the audio is worse than one that snaps).

When the backend provides no word boundaries, `currentWordRange` is the approximation described in document 05 §9; the HUD does not distinguish.

### 4.5 Show and hide policy

`HUDController` observes `PlaybackViewModel.isAudible` and `AppSettings.showHUD`:

- Appears (with `orderFrontRegardless()`) at the first `segmentStarted` event after a drained state, if `showHUD` is true.
- Stays while audio is queued or playing, and while any prompt is in the stack.
- Hides 4 s after the queue drains and the stack is empty, unless `hudPinned` is true.
- `showHUD == false` hides it immediately and suppresses future appearances. Prompts then surface only in the popover badge.
- A prompt arriving while hidden shows the HUD even if nothing is playing, for the prompt's lifetime plus 4 s.

### 4.6 Position

The panel frame is persisted in `AppSettings.hudFrame` (`CGRect?`, encoded as a string "x,y,w,h") on every `windowDidMove`. On restore, the frame is clamped to the `visibleFrame` of the screen containing its centre; if no screen contains it (display removed), it falls back to the default position: 12 pt below the menu bar and 12 pt from the right edge of the main screen's `visibleFrame`. When the active display configuration changes (`NSApplication.didChangeScreenParametersNotification`), the same clamp runs.

### 4.7 Hover behaviour

Hovering the panel shows the transport buttons at full opacity; otherwise they render at 55 %. Hover also pauses the auto-hide timer.

## 6. Hotkeys

`HotkeyManager` registers handlers at launch:

```swift
extension KeyboardShortcuts.Name {
    static let pauseResume  = Self("pauseResume",  default: .init(.j, modifiers: [.control, .option]))
    static let skipSegment  = Self("skipSegment",  default: .init(.k, modifiers: [.control, .option]))
    static let skipToLive   = Self("skipToLive",   default: .init(.l, modifiers: [.control, .option]))
    static let cycleSession = Self("cycleSession", default: .init(.semicolon, modifiers: [.control, .option]))
    static let cycleLevel   = Self("cycleLevel",   default: .init(.quote, modifiers: [.control, .option]))
    static let toggleMute   = Self("toggleMute")
    static let toggleHUD    = Self("toggleHUD")
}
```

| Name | Handler |
|---|---|
| `pauseResume` | `playback.togglePause()` |
| `skipSegment` | `playback.skipSegment()` |
| `skipToLive` | `playback.skipToLive()`; when not catching up, behaves like `skipSegment` |
| `cycleSession` | `sessions.activateNext()` — order is the popover sort order, wrapping, skipping `ended` sessions unless they are the only ones |
| `cycleLevel` | `sessions.cycleLevel(ofActive:)` quiet → answers → narrate → quiet, then speaks the new level name as an event ("Narrate.") |
| `toggleMute` | `playback.toggleMute()` |
| `toggleHUD` | `settings.showHUD.toggle()` |

With no active session, `pauseResume`, `skipSegment` and `cycleLevel` play a short low "nothing to do" tick through the chime path and do nothing else; `cycleSession` activates the first session if any exist. Conflicts with other apps are reported by the KeyboardShortcuts library UI when recording; Claudio does not attempt to detect them.

## 7. System notifications

Claudio does not post `UNUserNotification`s in v1. The HUD prompt stack and the popover badge are the only visual channels for "needs permission". The decision is recorded in document 13.

## 8. Accessibility

- Every button has `.accessibilityLabel` as listed above; state-dependent labels change with state.
- Session rows expose `.accessibilityElement(children: .combine)` with a value "<title>, <status>, <n> unread, level <level>" and an `.accessibilityAction(named: "Activate")`.
- The HUD panel sets `accessibilityRole` to `.group` and announces segment changes through `NSAccessibility.post(element:notification: .announcementRequested)` only when VoiceOver is running and captions are expanded.
- `accessibilityDisplayShouldReduceMotion` disables symbol effects, the caption cross-fade and HUD height animation.
- Colour is never the only indicator: status always has a glyph or text.
- Dynamic Type does not apply to menu bar extras; fixed sizes are used throughout.
